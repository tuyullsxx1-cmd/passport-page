# The Passport Page of a Country That Isn't There

An open passport spread for **Skarðey**, a small cold North Atlantic island nation (fishing, puffins, long winters, one small harbour capital, Hafnarvík). The left page is the data page — portrait, personal data, and a machine-readable zone — for Elín Margrét Jónsdóttir, born in Hafnarvík. The right page carries arrival and departure stamps from neighbouring Iceland and the Faroe Islands, a printed conditions-of-entry box, and a paid harbour-fee stamp. Every date agrees: the passport was issued 02 Jun 2024, all stamps fall after issue and before the 02 Jun 2034 expiry, in chronological order.
